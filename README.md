# AaloPro

Responsive, buildless HTML/CSS website based on the supplied AaloPro reference design.

Open index.html directly, or run `python3 -m http.server 8080` and visit http://localhost:8080.

- `index.html`: content and semantic page structure
- `styles.css`: responsive desktop/mobile styling
- `script.js`: accessible mobile navigation and icon rendering
- `assets/reference`: logo and image crops extracted from the user-provided graphics

The reference does not identify its exact font. Nunito Sans and Barlow Condensed provide a close visual match, with system fallbacks. Photography resolution is limited to the supplied 941px-wide reference. Replace crops with original photography for higher-resolution displays.

Try AaloApp and Request a demo open email enquiries to hello@aalopro.com. No app store URL was supplied. Statistics, prices, and testimonials reproduce the supplied demo content and should be verified before public marketing use.

Hosting uses a private ChatGPT Site. Static deployment files are copied to dist; edit root source files first.
